---
title: Installation
description: A guide on how to install Cover++.
---

Cover++ is distributed as an executable installer and a portable ZIP archive.

Both packages are available on [GitHub](https://github.com/ColoredCarrot/coverpp/releases).

## Installer

The installer allows you to select which components to install.
For example, you can choose not to install the documentation.

It can also add `cover++` to the system PATH.

## Portable Archive

The portable archive is a ZIP file that contains the Cover++ executable and all supporting files.
That includes DLLs, the report viewer, and this documentation.

It does not require installation or administrator privileges and can be run from any location.
